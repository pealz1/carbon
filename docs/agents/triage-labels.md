# Triage labels

Use these GitHub labels when triaging issues.

| Role | GitHub label | When to use it |
| --- | --- | --- |
| Needs triage | `needs-triage` | A maintainer still needs to assess the issue. |
| Needs information | `needs-info` | The reporter needs to supply more detail. |
| Ready for an agent | `ready-for-agent` | The issue is specified and ready for an agent to pick up. |
| Ready for a human | `ready-for-human` | Implementation requires a human. |
| Declined | `wontfix` | A maintainer has decided to close the request without implementing it. |

When an issue changes state, replace its previous triage label and keep its topic labels.
