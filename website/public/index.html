02 Why it’s fast

About4MB

Light by construction.

Carbon is written in Rust on Tauri 2, which uses the web engine already built into Windows instead of shipping its own browser. The whole app is about 4 MB. Spotify’s own desktop app runs to hundreds.

03 Setup

Three steps.
About two minutes.

Spotify’s 2026 developer rules limit each developer app to 5 users. So instead of sharing one, every listener makes a free Client ID of their own.

  1. Open the dashboard

    Log in at developer.spotify.com/dashboard with your Premium account.

  2. Create an app

    Any name. Redirect URI http://127.0.0.1:8888/callback. Tick Web API and Web Playback SDK.

  3. Paste your Client ID

    Copy it from the app’s Settings and paste it into Carbon on first launch.

05 FAQ

Fair questions.

Something else? Ask on GitHub.

Do I need Spotify Premium?

Yes. Carbon plays music with Spotify’s official Web Playback SDK, which only works with Premium accounts. Spotify also requires Premium to create the developer app used during setup.

Why do I need my own Client ID?

Spotify’s 2026 developer rules limit each developer app (each Client ID) to 5 users, so one shared ID would fill up almost immediately. Instead, every listener creates their own. It’s free and takes about two minutes: follow the setup guide.

Is my login safe?

You sign in on Spotify’s own page, so your password goes to Spotify, not to Carbon. The sign-in token Carbon receives is stored locally in Windows Credential Manager. Carbon has no servers, and it never needs your Client secret.

Details are in the privacy policy.

Is there a Mac or Linux version?

Windows first. Carbon is built for Windows 10 and 11 today. The source is on GitHub if you want to follow along.

Is it really free?

Yes, and open source. Carbon+ will be an optional one-time $4.99 upgrade for extras; the core app stays free.
