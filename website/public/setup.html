Make your own Client ID.

Carbon plays Spotify through a developer app that you own. It’s free and takes about two minutes. You need Spotify Premium: Spotify requires it for developer apps and for playback.

Why not one shared ID?

Spotify limits each developer app, and so each Client ID, to five users. A shared ID would fill up after five people, so every Carbon listener makes their own.

  1. Open the Spotify developer dashboard

    Go to developer.spotify.com/dashboard and log in with your Spotify account.

  2. Create an app

    Choose Create app and fill in the form like this:

    App name
    Anything, for example “My Carbon”
    App description
    Anything you like
    Redirect URI
    http://127.0.0.1:8888/callback Exactly this: 127.0.0.1, not localhost, and no slash at the end.
    APIs used
    Web APIWeb Playback SDK

    Accept Spotify’s developer terms, then choose Save.

  3. Paste your Client ID into Carbon

    1. Open your new app and go to its Settings.
    2. Copy the Client ID.
    3. Start Carbon and paste it in when it asks on first launch.

    Client ID, not Client secret. Carbon never needs the secret. Leave it hidden and don’t paste it anywhere.
